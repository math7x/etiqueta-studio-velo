Como usar o Etiqueta Studio

  1. Meça uma etiqueta da sua folha e configure largura, altura, linhas, intervalos e margens.
  2. Em Editar etiqueta, monte o desenho. Ele é compartilhado por todas as posições.
  3. O desenho mostra os campos do Velo, como no iReport. A prévia real usa dados automáticos de demonstração para testar o layout.
  4. Baixe a folha de calibração e imprima em 100%, tamanho real. Desative ajustar à página. A régua deve medir 10 cm.
  5. Use os deslocamentos X/Y para mover a grade. Se o erro aumentar ao descer a folha, confira altura e intervalo vertical.
  6. Gerar JRXML + JASPER salva um pacote. Extraia os dois modelos e importe pelo procedimento do seu sistema.
  7. Salvar projeto guarda desenho e medidas para reabrir depois. Escolha onde salvar o arquivo na janela do Windows.

Atalhos: Ctrl+Z desfaz; Ctrl+Y refaz; Ctrl+D duplica; Delete exclui; setas movem aproximadamente 0,035 cm (Shift: 0,176 cm). Objetos bloqueados não se movem.

Abre projetos deste editor e JRXML simples. Arquivos Zebra .lbl/.nlbl, imagens e QR Code não são suportados. Esta versão já inclui os componentes necessários para funcionar.
